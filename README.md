# Resaeni

Korean animation / Aeni discovery project.

## Stack

Frontend:

- React
- Vite
- Chakra UI
- React Router
- TanStack Query
- Axios
- Cloudflare

API:

- Cloudflare Workers
- Hono
- TypeScript

## Development

Frontend:

```bash
npm install
npm run dev
```

Worker:

```bash
cd worker
npm install
npm run dev
```
